# 👋 Welcome to My Personal Profile Website

Hi, and thanks for stopping by! This repository contains my personal profile website, a two-page site built with **Nuxt.js** and styled with **Tailwind CSS**.

## What's Inside

- **Homepage:** a short introduction about me, my profile picture, and a welcome message
- **Profile page:** my personal information, educational background, skills and interests, and hobbies

## Why I Built This

I made this project as a school activity to learn how Nuxt works: file-based pages, reusable components, shared layouts, and Tailwind CSS for styling.

## Run It Locally

```bash
git clone https://github.com/your-username/nuxt-profile.git
cd nuxt-profile
npm install
npm run dev
```

Then open <http://localhost:3000> in your browser.

Thanks for visiting, and feel free to explore the code! 😊
